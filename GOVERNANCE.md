# Governance

Jackson Harris (@jackson-harris-iii) is the initial maintainer and release operator. Anyone can propose changes through issues and pull requests. Maintainer review determines merges; community votes inform project priorities but do not promise a build, grant or payment.

Source is public under MIT as described in LICENSE and NOTICE.md. Hosting bills, secrets, live participant records and publishing access remain with the deployment operator. Repositories and individual project teams do not automatically gain access to the live portal.

For now, repositories stay under Jackson's personal account. Revisit an organization when multiple active maintainers need independent administration, multiple communities depend on releases, or grant/sponsor governance requires shared ownership. Any transfer should preserve Git history and issues and be announced before changing contributor workflows.
