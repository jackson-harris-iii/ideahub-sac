# Reporting a security issue

Do not put credentials, personal records or exploit details in a public issue. Contact the maintainer privately through [Jackson's LinkedIn](https://www.linkedin.com/in/jacksonharris3/) to arrange a private report. No response-time SLA is promised.

Use synthetic local records for testing. The included admin adapter is only for the trusted Sites dispatcher and explicitly denies access unless enabled by its operator. A direct-host deployment needs verified authentication and must strip or ignore spoofed identity headers.
